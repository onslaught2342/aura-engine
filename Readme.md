# Aura Engine

> **I find normal PowerPoints boring, so I built something better.**

Aura Engine is a cinematic presentation and visual engine designed to turn presentations into interactive visual experiences instead of static slides.

Rather than clicking through a collection of boxes, text, and bullet points, Aura Engine uses procedural visuals, transitions, motion, and real-time customization to make the presentation itself part of the experience.

## Why?

Traditional PowerPoint presentations usually look like this:

**Slide → Click → Slide → Click → Slide → Click**

I wanted:

**Visual → Motion → Transition → Atmosphere → Content**

So instead of making another PowerPoint, I built an engine.

## What It Does

Aura Engine provides a presentation environment with:

- Procedural background effects
- Cinematic transitions
- Smooth crossfades
- Real-time visual customization
- Dynamic typography
- Animated visual elements
- Configurable presentation scenes
- Full-screen presentation mode
- A visual-first approach to presenting information

The goal is simple:

> **Make the presentation feel like an experience, not a slideshow.**

## Built For

Aura Engine can be used for:

- School presentations
- Projects and demonstrations
- Events
- Product showcases
- Creative presentations
- Interactive visual displays
- Digital installations
- Anything where a normal slideshow feels too static

## The Philosophy

PowerPoint is good at putting information on slides.

Aura Engine is built around a different question:

> **What if the presentation itself was the software?**

Instead of designing every slide as an isolated image, the engine handles visuals, transitions, effects, and interaction as part of one system.

That means the presentation can react, move, transition, and evolve rather than simply switching between pages.

## Visual Engine

The background system uses procedural effects to generate visuals dynamically.

This means the visuals are not simply a collection of static background images.

They can be:

- Animated
- Configured
- Combined
- Transitioned
- Modified in real time

The result is a presentation that can have its own visual identity instead of looking like a default template.

## Technology

Built with modern web technologies, including:

- React
- TypeScript
- Vite
- CSS
- Procedural visual effects
- Browser-based rendering

The project is designed to run directly in the browser without requiring traditional presentation software.

## Running Locally

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local address provided by Vite.

## Building

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
